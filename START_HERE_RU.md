# DeepCool AK500 DIGITAL WH: обновление версии 0.2

Новая версия считывает **температуру процессора и его общую загрузку каждую секунду**.
Экран переключается автоматически: 5 секунд температура °C, затем 5 секунд загрузка %, затем повтор.

## Что требуется

- Windows 10/11 x64.
- Уже установленный AMD Ryzen Master Monitoring SDK (у тебя установлен).
- Rust с целевой платформой MSVC.
- Visual Studio Build Tools с компонентом Desktop development with C++.
- Запуск программы от имени администратора, чтобы читать датчики AMD.

**PawnIO, приложение DeepCool и отдельный фоновый процесс не нужны.**
Нужны установленные DLL и драйвер самого AMD SDK. Маленький C++-адаптер автоматически собирается внутрь единственного exe.

## 1. Обнови исходники

Открой репозиторий: https://github.com/DaytonCL/DeepCoolRust

Если скачивал ZIP, скачай его заново и распакуй в новую папку.
Если использовал git clone, в каталоге проекта выполни:

    git pull

## 2. Собери в PowerShell в папке Cargo.toml

    cargo build --release
    cargo test

Если Cargo не найдёт AMD SDK, проверь каталог:

    C:\Program Files\AMD\RyzenMasterMonitoringSDK\include
    C:\Program Files\AMD\RyzenMasterMonitoringSDK\bin

При установке SDK в другую папку перед сборкой задай путь к корню SDK:

    $env:AMDRMMONITORSDKPATH = 'D:\Path\To\RyzenMasterMonitoringSDK'
    cargo build --release

## 3. Проверь датчики без записи в дисплей

Открой PowerShell от имени администратора и перейди в папку проекта.
Выполни:

    .\target\release\ak500-digital-lite.exe --dry-run --once

Программа должна показать реальную температуру в °C и загрузку CPU в процентах.
Режим dry-run не отправляет ничего на USB.

Если ошибка SDK init code -2, проверь наличие Platform.dll в папке SDK bin.
Если ошибка SDK init code -4 или -5, попробуй запуск от имени администратора.
Если ошибка компиляции, пришли полный вывод cargo build --release.

## 4. Запусти обновление экрана

Закрой официальное приложение DeepCool, чтобы две программы не обращались к дисплею одновременно.

    .\target\release\ak500-digital-lite.exe --quiet

Последовательность:
- 0–5 с: температура CPU (каждую секунду новая).
- 5–10 с: загрузка CPU (каждую секунду новая).
- 10–15 с: температура, и далее по кругу.

Остановка — Ctrl+C.

Для просмотра всех показателей в терминале каждую секунду запусти без --quiet:

    .\target\release\ak500-digital-lite.exe

## Важные ограничения

- Текущий исходный код ещё не проверялся компиляцией на твоей Windows, хотя предыдущая версия без температуры уже успешно работала.
- AMD SDK не следует опрашивать чаще 1 раза в секунду.
- Если SDK вернёт ошибку или недостоверную температуру, программа завершится вместо отправки выдуманного значения.
- Программа не управляет вентиляторами и не меняет службы, драйверы, автозагрузку и BIOS.
- Не удаляй установленный SDK: он нужен для температуры.
